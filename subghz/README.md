# Sub-GHz

Collection of Sub-GHz captures, testing notes, signal analysis, and reference material.

## Contents

### Captures

Recorded Sub-GHz signals from authorized devices and systems.

Examples:

* Garage door remotes
* Gate openers
* Weather stations
* Wireless sensors
* Remote switches

### Analysis

Signal investigation and protocol identification.

Topics:

* Frequency analysis
* Modulation types
* Static vs rolling codes
* Protocol identification

### Testing

Authorized testing and experimentation.

Examples:

* Signal replay testing
* Range testing
* Receiver compatibility testing

### References

Useful information and documentation.

Topics:

* Common frequencies
* Protocol documentation
* Flipper Zero Sub-GHz capabilities
* CC1101 notes

## Notes

This directory is intended for educational, research, and authorized testing activities.

Always ensure you have permission before capturing or transmitting signals from systems you do not own or administer.
