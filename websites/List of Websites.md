# Flipper Zero Websites

A collection of useful websites and web tools for the Flipper Zero ecosystem.

---

## Official Resources

### Flipper Lab
https://lab.flipper.net/

Official web tools from Flipper Devices. Includes the online application catalog, firmware downloads, file management, device updates, and other utilities for managing your Flipper Zero.

---

## Community Tools

### Dictionary Enricher
https://matzzebib.github.io/DictEnricher/

A utility for generating and expanding custom dictionaries used for password auditing and testing workflows. Useful when creating targeted wordlists from names, dates, keywords, and other custom inputs.

### Flipper FAP Actions
https://joelewis012.github.io/flipper-fap-actions/index.html

A searchable web interface for discovering Flipper Zero applications (FAPs), their GitHub repositories, and installation resources. Helpful for finding community-developed apps beyond the official catalog.

---

## Reference Databases

### Flipper IRDB
https://github.com/flipperdevices/flipperzero-irdb

The largest public collection of infrared remote files for the Flipper Zero. Contains TV, audio, projector, air conditioner, and other IR device databases.

### Awesome Flipper Zero
https://github.com/djsime1/awesome-flipperzero

A curated list of Flipper Zero resources, applications, firmware projects, hardware add-ons, documentation, and community tools.

### Awesome Flipper Zero Apps
https://github.com/xMasterX/awesome-flipperzero-apps

A community-maintained directory focused specifically on Flipper Zero applications and plugins.

---

## Firmware

### Momentum Firmware
https://github.com/Next-Flip/Momentum-Firmware

A popular custom firmware that adds additional features, interface improvements, and community-developed enhancements.

### Official Firmware
https://github.com/flipperdevices/flipperzero-firmware

The official open-source firmware maintained by Flipper Devices.

---

## ESP32 WiFi Development Board

### ESP32 Marauder
https://github.com/justcallmekoko/ESP32Marauder

Firmware for ESP32-based WiFi development boards that integrates with the Flipper Zero for wireless network analysis, packet capture, and wireless testing on networks you own or are authorized to assess.

### Evil Portal
https://github.com/bigbrodude6119/flipper-zero-evil-portal

A captive-portal demonstration and educational tool for ESP32 WiFi development boards used to explore how portal-based authentication systems work.
