# Flipper Zero Websites

A collection of useful websites, tools, documentation, and community resources for the Flipper Zero ecosystem.

---

## Official Resources

### Flipper Lab

https://lab.flipper.net/

Official web tools from Flipper Devices. Includes firmware updates, application management, device file access, and other utilities for managing a Flipper Zero from a web browser.

### Flipper Documentation

https://docs.flipper.net/

Official documentation covering hardware features, firmware functionality, development resources, and troubleshooting guides.

### Flipper Forum

https://forum.flipper.net/

The official community forum where users discuss firmware, hardware modifications, applications, troubleshooting, and development projects.

---

## Community Tools

### Dictionary Enricher

https://matzzebib.github.io/DictEnricher/

A utility for generating and expanding custom dictionaries used for password auditing and testing workflows. Useful for creating targeted wordlists from names, dates, keywords, and other custom inputs.

### Flipper FAP Actions

https://joelewis012.github.io/flipper-fap-actions/index.html

A searchable interface for discovering Flipper Zero applications, GitHub repositories, and installation resources.

### Flipper Maker

https://flippermaker.github.io/

A collection of web-based generators and utilities for creating Flipper-compatible files and experimenting with Flipper Zero features.

## Application Catalogs

### Awesome Flipper Zero Apps

https://github.com/xMasterX/awesome-flipperzero-apps

A curated collection focused specifically on Flipper Zero applications and plugins available from the community.

## Databases & Reference Collections

### Flipper IRDB

https://github.com/flipperdevices/flipperzero-irdb

The largest public collection of infrared remote files for the Flipper Zero. Includes televisions, audio equipment, projectors, air conditioners, and many other IR-controlled devices.

### Awesome Flipper Zero

https://github.com/djsime1/awesome-flipperzero

One of the most comprehensive collections of Flipper Zero resources, including firmware, hardware add-ons, applications, tutorials, documentation, and community projects.

## Firmware

### Official Firmware

https://github.com/flipperdevices/flipperzero-firmware

The official open-source firmware maintained by Flipper Devices.

### Momentum Firmware

https://momentum-fw.dev/

A popular community firmware featuring additional customization options, interface enhancements, and extra functionality beyond the official firmware.

### Momentum Firmware Source

https://github.com/Next-Flip/Momentum-Firmware

Source code repository for Momentum Firmware, including releases, issue tracking, and development information.

## ESP32 WiFi Development Board Resources

### ESP32 Marauder

https://github.com/justcallmekoko/ESP32Marauder

Firmware for ESP32-based WiFi development boards that can integrate with the Flipper Zero for wireless network analysis, packet capture, and educational security testing on authorized networks.

### Evil Portal

https://github.com/bigbrodude6119/flipper-zero-evil-portal

A captive portal demonstration project for ESP32 development boards that can be used to learn how portal-based authentication systems function.
