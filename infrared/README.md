# Infrared

Collection of infrared remote files, testing notes, and reference material.

## Contents

### Personal Remotes

Remote files created from devices I own.

Examples:

* Televisions
* Sound systems
* Receivers
* Air conditioners
* Projectors

### Community Databases

Reference collections and imported resources.

Examples:

* Flipper IRDB
* Converted Pronto files
* Manufacturer-specific collections

### Testing

Verification and compatibility testing.

Examples:

* IR replay testing
* Range testing
* Device compatibility testing

### References

Useful documentation and resources.

Topics:

* Infrared protocols
* Raw captures
* Universal remotes
* Device compatibility

## Notes

The Flipper IRDB repository is included separately within this directory and serves as the primary reference database for infrared devices.

Store personal captures and custom remotes separately from imported databases whenever possible.
