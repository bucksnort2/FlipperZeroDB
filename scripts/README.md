# Scripts

Collection of utility scripts, automation tools, and repository maintenance resources.

## Contents

### Repository Management

Scripts used to maintain this repository.

Examples:

* Submodule updates
* File organization
* Index generation
* Backup utilities

### Flipper Utilities

Tools related to Flipper Zero file management.

Examples:

* File converters
* Metadata extraction
* Data cleanup tools

### Hardware Utilities

Scripts related to external hardware.

Examples:

* ESP32 utilities
* Serial communication tools
* Firmware management helpers

### Development

General-purpose development scripts.

Examples:

* Testing utilities
* Build helpers
* Documentation generation

## Notes

Scripts should be documented whenever possible.

Include:

* Purpose
* Usage instructions
* Dependencies
* Expected output

This directory is intended for supporting tools and automation rather than Flipper application development.
